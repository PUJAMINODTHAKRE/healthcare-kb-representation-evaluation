# Reproducibility Boundary

This repository is deliberately **data-free**.

## Publicly documented here

- Research question
- Seven representation paradigms
- Five-query benchmark structure
- Four evaluation dimensions
- Reasoning-depth definition
- Published comparative interpretation
- Author contribution roles
- Publication metadata

## Not distributed here

- Patient-level records
- Clinical attributes
- Private project files
- Publisher-formatted article PDF
- Any unpublished collaboration material

A full experimental reproduction would require the original dataset and implementation artefacts. This repository therefore serves as a transparent methodological companion rather than claiming to be a complete replication package.
